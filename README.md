# Post Composer - React

A simple React application that allows users to compose posts for Twitter or LinkedIn.

## Features

- Select Twitter or LinkedIn
- Twitter limit: 280 characters
- LinkedIn limit: 3000 characters
- Live character counter
- Error message when the selected platform's limit is exceeded
- Responsive UI

## Run locally

Make sure Node.js is installed.

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite, usually:

http://localhost:5173
